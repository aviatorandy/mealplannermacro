# Protein Breakfast Planner

A single-page site for planning high-protein, weight-loss-friendly breakfasts built around Greek yogurt.

**Open it:** open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → deploy from this branch, root folder).

## What it does
- **Targets** from your weight and calories: daily protein (1.2-1.6 g/kg), breakfast protein (~30% of daily, 25-40 g), breakfast calories, fiber (14 g per 1,000 kcal) and an added-sugar cap (10% of calories). Optional Mifflin-St Jeor calorie estimate.
- **Breakfast builder**: 37 foods with protein-per-100-kcal badges. A protein ring, calorie/fiber/sugar meters and a macro split update as you add servings.
- **Suggestions**: best protein-per-calorie add-ons when you're short, fiber boosters, and swaps (flavored yogurt → plain, granola → pumpkin seeds, honey → cinnamon).
- **11 recommended breakfasts** (6 Greek yogurt, 5 "switch it up") plus a "watch out" café parfait for comparison.
- **7-day log**: protein per day vs target and a variety tracker that suggests something new when you repeat the same base.

Data is saved in your browser's localStorage, so it stays on that device and browser only.
