# Protein Meal Planner

A single-page, high-protein meal planner for weight loss: breakfast, lunch, dinner and snacks, built around a daily protein goal (default 200 g).

**Open it:** open `index.html` in a browser, or turn on GitHub Pages (Settings > Pages > deploy from this branch, root folder).

## What it does
- **My day (top):** a protein ring split by meal, plus four meal cards with food icons, protein vs each meal's target and calories. "Swap meal" cycles through ideas in one tap.
- **Meal ideas:** 23 recipes (6 breakfast, 5 lunch, 6 dinner, 5 snacks) plus a "watch out" café parfait for comparison.
- **Customize (bottom):** 65 food tiles with protein per serving and a protein-per-100-kcal bar, a plate panel with meters, suggestions and swaps, and "Save as my default" per meal.
- **Last 7 days:** saved days stacked by meal against the goal.
- **Goals:** daily protein, calories (optional Mifflin-St Jeor estimate), current and goal weight with the 0.7-1.0 g/lb range, and the protein split across meals.
- **Cook view:** each meal with amounts and steps, a grocery list for 1-7 days, notes for the cook, and "Copy plan as text".

Hosted as a claude.ai artifact, the plan syncs live to anyone it is shared with. Opened as a plain file or on GitHub Pages, it saves in the browser only.
